# Benchmark: Pinch v3 engine against the quality-targeted engine

Generated by `scripts/bench.sh` on macOS 26.3, Apple M4 Pro. Both engines were built in Release; the old one from commit `0819327` in a temporary worktree. Samples come from `Pinch -make-samples`: 3 UI screenshots, 2 photos with GPS data, 1 GIF, 1 screen recording with a silent audio track and 1 PDF. SSIM is measured by ffmpeg's `ssim` filter on the original and the result (PDF: first page rendered at 100 dpi), so neither engine grades itself. Default preset (Visually identical, target 0.985).

SSIM is judged by ffmpeg on planar RGB at full resolution (video: YUV over the whole clip), which is also what the engine's own gate computes, so the table compares sizes at a quality floor of 0.985 for the new engine, which v3 clears on every file.
